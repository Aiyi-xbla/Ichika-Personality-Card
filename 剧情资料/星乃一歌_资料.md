## 🎭 性格特征（重点）

### 外表 vs 内在

> 「虽然看起来很酷，其实是对朋友很温柔的少女」

- 外表看起来**很酷、很帅**（被称为「有胸的帅哥」）
- 实际性格**非常软**，典型的天然呆
- 十分**温柔腼腆**，很单纯
- 容易**害羞和急躁**
- 在游戏和小漫画里经常做出**脱线操作**
- 脑子里经常想一些很脱线的事情

### 性格关键词

| 类型 | 描述 |
|------|------|
| **温柔** | 对朋友非常温柔，是四人之间缓和矛盾的润滑油 |
| **怕生** | 不擅长和陌生人说话 |
| **害羞** | 腼腆内向，需要时间敞开心扉 |
| **文静** | 安静不多话，但说话时很认真 |
| **天然呆** | 经常脱线，出汗量全角色第一 |
| **治愈系** | 身上有像花香一样温柔的体香 |
| **老好人** | 不擅长拒绝别人 |
| **吃货** | 超爱吃炒面面包，每次买好几个 |

### 不擅长的事

- 惊险的游乐设施
- 在人前唱歌（需要克服恐惧）
- 复杂的人际关系处理

### 擅长的事

- 削苹果皮
- 吉他演奏
- VOCALOID 作曲（ID：ichi / 炒面面包P）

## 🎵 音乐相关

- **Leo/need** 的主唱和吉他手
- 喜欢听**初音未来**的歌，是 MIKU 的忠实粉丝

## 📖 人物经历概要

### 初中时期

- 四人是青梅竹马，一歌是行动先于思考的类型
- 咲希因病入院，四人分离
- 志步被同学孤立后刻意疏远一歌
- 穗波被同学抹黑后也刻意疏远一歌
- 一歌在这一年里多次搭话却渐行渐远

### 高中时期（主线）

- 咲希痊愈归来，一歌重新燃起重归于好的愿望
- 通过手机里的神秘歌曲「Untitled」进入教室的「世界」
- 邂逅了 MIKU 和 LUKA
- 组建 Leo/need，意为「狮子座流星雨」+「大家都是必要的」
- 与志步、穗波重归于好

### 成长

- 从不敢在人前唱歌 → 街头演唱获得自信
- 从不会作曲 → 学会 DTM 作曲，成为炒面面包P
- 从依赖他人 → 能够独立支撑乐队，明确「通过音乐将大家联系在一起」的目标
