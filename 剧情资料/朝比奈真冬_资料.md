## 🎭 性格特征（重点）

### 核心矛盾

> 「表面上像是完美的优等生，各方面都十分完美的她，却……？」

- 她一直按照母亲的要求努力做着「好孩子」
- 结果逐渐**迷失了自我**
- 直到有一天发现自己**体会不到味觉，甚至不再记得爱好、情感和梦想**
- 「我」在哪里？

### 性格关键词

| 类型 | 描述 |
|------|------|
| **外热内冷** | 表面开朗幽默，内心空洞 |
| **述情障碍** | 不擅长表达自己的真实情感 |
| **三无/无感情** | 情感淡漠，死鱼眼 |
| **认真执着** | 做事非常认真，甚至有些偏执 |
| **沉重** | 内心背负着很大的压力 |
| **天然黑** | 无意识间说出很毒的话 |
| **味觉缺失** | 因心理压力失去味觉 |
| **疑似抑郁症** | 长期压抑自我导致的心理问题 |

### 她的「表面」

- **优等生**：成绩好、能力强、人缘好
- **班长**：被同学信任
- **温柔可靠**：被同学称为「天使」「女神」
- **什么都做得到**，不管怎么麻烦也不会生气

### 她的「真实」

- 不知道自己的喜好是什么
- 不知道自己想说什么
- 甚至不知道自己是谁
- 通过音乐活动逐渐找到自我，把25时当成归宿

## 📖 人物经历概要

### 优等生的枷锁

- 父母希望她学体面的医学 → 她放弃做看护师的梦想
- 同学觉得优等生「没有时间玩乐」→ 她放弃和他人去玩
- 只要满足大家的期望，大家都会很开心
- 直到失去味觉、失去情感、失去自我

### 25时的救赎

- 通过音乐活动找到归宿
- 和奏、绘名、瑞希一起在深夜的网络世界里寻找真实的声音
- 最终选择**离家出走**，向奏寻求帮助
